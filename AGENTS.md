# AI Agent Instructions for MiClan

## What this repository is
- Flutter mobile app targeting Android, with Firebase backend integration.
- Root app is in `lib/`, especially `lib/main.dart` which contains most app logic.
- Firebase backend code lives in `functions/` and is referenced by `firebase.json`.
- This repo includes bugfix documentation in Spanish: `README.md`, `README_NOTIFICACIONES_DOZE.md`, and `Etapa2.md`.

## Primary areas of focus
- `lib/main.dart` is the main application entrypoint and is currently monolithic; prefer smaller targeted edits and avoid large refactors unless explicitly requested.
- `lib/firebase_options.dart` is generated by FlutterFire and should only be updated by the FlutterFire CLI or when Firebase app config changes.
- `functions/index.js` is the Cloud Function that sends FCM data-only notifications.
- `firebase.json` points at `functions/` for deployment.
- `pubspec.yaml` defines dependencies like Flutter, Riverpod, GoRouter, Firebase packages, and Android-specific plugins.

## Build and deployment commands
- Install Flutter dependencies: `flutter pub get`
- Clean and refresh: `flutter clean && flutter pub get`
- Run tests: `flutter test`
- Analyze code: `flutter analyze`
- Deploy Cloud Functions from the root functions folder:
  - `cd functions`
  - `npm install`
  - `firebase deploy --only functions`

## Important repo conventions and details
- The app uses `flutter_riverpod` for state management and `go_router` for navigation.
- FCM messages are sent as data-only payloads; the app relies on a local notification service to show notifications.
- Android wake/screen-on and battery optimization behavior is a key bugfix area. Use `README_NOTIFICACIONES_DOZE.md` for notification/Doze mode context.
- `Etapa2.md` contains project architecture notes, decision rationale, and known limitations.
- There are multiple functions directories in the repo, but the authoritative backend code is the root `functions/` folder referenced by `firebase.json`.

## When editing
- Prefer small, incremental changes in `lib/main.dart` because it is large and carries many app initialization concerns.
- When modifying Firebase behavior, check `functions/index.js` and `README_NOTIFICACIONES_DOZE.md` first.
- Do not assume iOS/workflows are complete; the current app appears primarily Android-focused.
- Keep Spanish documentation in mind; comment and variable names may use Spanish conventions.

## Useful files
- `README.md` - high-level fix summary and install/deploy instructions.
- `README_NOTIFICACIONES_DOZE.md` - notification/Doze mode bugfix context.
- `Etapa2.md` - project architecture, feature decisions, and refactor notes.
- `firebase.json` - Firebase codebase configuration.
- `firestore.rules` / `firestore.indexes.json` - Firestore security and indexes.
